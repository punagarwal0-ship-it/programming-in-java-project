# Project Statement

## Problem Statement

Small shops and college-level store operations often maintain product, supplier, and stock details manually. This can cause incorrect stock counts, missed reorder requirements, and difficulty in preparing inventory reports. A simple computerized system is needed to store product information, update stock, manage suppliers, and provide useful reports.

## Scope of the Project

The project covers the basic operations of an inventory system through a command-line interface. It allows users to manage product records, maintain supplier details, add or sell stock, receive low-stock alerts, track stock movements, update prices, and generate inventory reports. The project uses an H2 database for local storage.

The project does not include online payments, barcode scanning, multi-user login, cloud hosting, or automatic supplier ordering.

## Target Users

- Small shop owners
- Store assistants
- College laboratory or department stores
- Small warehouse operators
- Students learning Java and database integration

## High-Level Features

- Product CRUD operations
- Electronic and Grocery product hierarchy
- Stock addition and sales
- Low-stock reorder alerts
- Supplier management
- Price updates
- Stock movement history
- Inventory value calculation
- Database persistence
- Command-line menu
- Input validation and exception handling
- Inventory report generation
